伪标签师生检测与 DINO 系列在目标检测中的应用综述

调研日期：2026-07-03 工具：ai4scholar MCP（Semantic Scholar 检索、snippet、全文读取） 场景：VFM-assisted YOLO distillation for low-label aerial small-object detection

结论概览。伪标签师生目标检测在少标注、小样本和零样本场景中的有效性，主要来自六类策略：更强或更稳定的教师、更可靠的伪标签筛选、弱强增强一致性、软标签/低置信标签利用、类别与尺度不均衡校正，以及用 VFM/开放词汇模型补充语义先验。对航拍小目标而言，最值得优先采用的是“训练期多教师伪标注 + 切片保持分辨率 + 类别自适应阈值 + 定位一致性/密度/objectness 复筛 + YOLO-only 学生部署”的组合。

DINOv1/v2/v3 在目标检测中的角色要和 DINO 检测器区分开：DINOv1/v2/v3 是自监督视觉表征模型，通常用作前景发现、冻结特征、伪标签评估、特征蒸馏或检测骨干；Grounding DINO 中的 DINO 则是 DETR 系列的检测器改进。DINOv3 相比 DINOv2 的关键进展是更稳定的高分辨率 dense features，原文报告冻结 7B/16 backbone 的 COCO 检测 mAP 可达 66.1，这说明它很适合作为训练期教师或 objectness/feature teacher，但对部署期 YOLO 学生仍应保持离线蒸馏而非教师在线推理。

1. 检索方法与证据范围

本报告使用 ai4scholar MCP 的 Semantic Scholar 检索与全文读取能力完成。检索覆盖四条主线：第一，经典半监督目标检测中的 teacher-student pseudo labeling，包括 Unbiased Teacher、Soft Teacher、LabelMatch、Dense Teacher、OneTeacher 等；第二，小样本和极少标注检测中的 adaptive pseudo labeling、prototype soft labels、confidence-tiered pseudo labels；第三，开放词汇和零样本检测中由 CLIP、Grounding DINO、YOLO-World、RemoteCLIP 等模型生成伪标签或语义候选的做法；第四，DINOv1、DINOv2、DINOv3 这类自监督视觉基础模型在目标发现、检测骨干、特征增强、伪标签评估和蒸馏中的使用方式。

检索关键词包括但不限于：teacher student pseudo label few-shot object detection、Unbiased Teacher semi-supervised object detection、Soft Teacher object detection、open vocabulary object detection pseudo label、DINO self-supervised vision transformer object detection、DINOv2 object detection dense prediction、DINOv3 Gram anchoring dense features detection、remote sensing semi-supervised object detection pseudo label、Grounding DINO YOLO teacher student、YOLO-World real-time open vocabulary object detection。其中 DINOv2 和 DINOv3 原文通过 ai4scholar 的全文读取工具复核了训练机制和检测指标；DINOv3 的 COCO mAP 66.1 来自其原文检测附录。

术语边界。文献中至少有两个“DINO”。其一是 Caron/Oquab/Siméoni 系列的自监督视觉表征模型 DINO、DINOv2、DINOv3；其二是 Zhang 等提出的 DETR with Improved DeNoising Anchor Boxes，即 DINO 检测器。Grounding DINO 是把 DINO 检测器与 grounded pre-training 结合，不等同于 DINOv1/v2/v3 自监督表征模型。

2. 伪标签师生检测的策略谱系

目标检测中的伪标签比分类更难，因为每个伪标签同时包含类别、框位置、尺度、重复框抑制和背景判定。少标注时，教师检测器往往对少数类和大目标过度自信，对小目标、遮挡目标、长尾类和领域迁移目标低置信或漏检；学生再用这些标签训练会放大 confirmation bias。因此有效方法几乎都在回答同一组问题：哪些教师预测可用，哪些低置信预测应该保留，类别分布是否被扭曲，框定位是否可信，学生是否在强增强视图上保持一致，以及教师更新是否过快导致伪标签分布漂移。

经典 SSOD 的主干范式是 mean teacher 或 teacher-student self-training：教师在弱增强图像上产生伪框，学生在强增强图像上学习，教师由学生 EMA 更新。Unbiased Teacher 发现 SSOD 中有明显 pseudo-labeling bias，并用 class-balance loss 减轻过度自信伪标签导致的类别偏置；Soft Teacher 则把教师分类分数作为未标注框分类损失权重，并用 box jittering 判断框回归可靠性；LabelMatch 从 distribution-level 和 instance-level 同时修正 label mismatch；Dense Teacher 进一步把 sparse pseudo boxes 替换为 dense pseudo-label，减少 NMS/阈值等后处理超参损失的信息。

2.1 置信阈值从全局固定转向自适应

早期伪标签检测常采用一个全局 confidence threshold，但这在少标注检测里很脆弱。类间样本量、目标尺度、目标纹理和场景背景差异很大时，同样的 0.7 分数不代表同样的伪标签质量。Adaptive Pseudo Labeling for FSOD 用每个 novel class 的置信分布分位数决定 class-adaptive threshold，并融合预训练 few-shot detector 与 teacher model 两路 CATF 结果。LabelMatch 进一步把未标注数据的类别分布近似约束引入阈值，使用 label-distribution-aware confidence thresholds。遥感 CTPL 的结果也说明，在极少标注情况下只保留高置信伪标签会覆盖不足；中等置信标签在质量可控时反而能明显改善学生性能。

对小目标检测而言，自适应阈值不只是按类别分组，还应按面积段和成像条件分组。例如航拍中同一类别车辆在不同高度、光照和拥堵场景下分数分布差异很大，若统一阈值，密集场景中的小车和遮挡行人会被系统性丢掉。更稳妥的方案是将筛选拆成两阶段：第一阶段用较宽松分数阈值保证召回，第二阶段用定位稳定性、多尺度一致性、DINOv3 patch foreground/objectness、教师间一致性来筛掉噪声。这样可以避免把分类置信度当作伪标签质量的唯一代理。

2.2 定位质量比分类分数更关键

目标检测伪标签的主要噪声不只是错类，还包括框偏移、漏掉目标边界、重复框和只覆盖物体局部。Soft Teacher 的 box jittering 是一个重要信号：如果对伪框做扰动后预测仍稳定，框回归标签更可信。遥感 oriented object detection 文献进一步引入 localization quality metric、aspect ratio-aware localization loss reweighting 和旋转信息增强，因为航拍目标常有任意方向、极端长宽比和密集邻接。Dense Teacher、CDPL、RemoteDPL 则强调 dense pseudo-label 或 dense target producer，理由是 sparse boxes 加 NMS 可能损失场景中的细粒度对象信息。

本项目若使用 Grounding DINO/YOLO-World 产伪标签，不宜只用文本匹配分数筛框。对 VisDrone 这类小目标数据，框的几何可信度可以来自四个信号：同一图像不同尺度切片的框是否重合；不同教师是否在相近区域给出 objectness；DINOv3 patch 相似图是否在框内外形成清晰前景差；训练中 YOLO 学生对该框的回归残差是否持续下降。报告建议把这些信号写成配置驱动的 pseudo label scoring，而不是固化在脚本中。

2.3 低置信伪标签的正确用法

低置信预测不能简单等同于噪声。LPLD、PS-TTL、confidence-tiered pseudo labeling 等工作说明，低置信候选往往包含 foreground recall 信息，尤其在 domain shift、few-shot novel classes、小目标或弱教师场景中，高置信阈值会产生严重 false negative。更合理的做法是降低它们在类别损失中的硬监督权重，转而把它们用于 objectness、proposal recall、prototype similarity、soft label 或 feature distillation。也就是说，低置信标签可以告诉学生“这里可能有物体”，但不一定强迫学生相信“这是某个具体类别”。

这种策略特别适合航拍小目标。小目标在开放词汇教师中常表现为文本类别分数低、框边界粗糙，但前景性仍然明显。DINOv3 或 DINOv2 的 dense feature 可以作为与类别无关的前景/相似性证据；Grounding DINO 和 YOLO-World 则提供类别语义。组合后可以将候选划分为三层：高置信硬标签用于正常检测损失；中置信软标签用于带权类别损失和框回归；低置信 foreground-only 标签用于 objectness 或 feature consistency。这样比简单删除低分框更能提升召回。

3. 小样本/零样本检测中的伪标签机制

few-shot object detection 的常规问题是 base/novel 偏置：模型在 base classes 上有较充分训练，但 novel classes 的 few-shot support 不足以覆盖外观变化。Semi-Supervised FSOD via Adaptive Pseudo Labeling 指出，base dataset 中实际上可能包含大量未标注 novel instances，若能通过 teacher 和预训练 FSOD detector 发现这些实例，就能缓解 novel 类数据稀缺。其 CATF 根据每个 novel class 的分数分布分位数设阈值，并融合两路伪标签，核心是让阈值跟随类别难度而变化。

LEDetection/SoftER Teacher 把问题进一步设为 base 和 novel 标注都稀缺的 semi-supervised FSOD。其发现是：未标注数据可通过 region proposals 显著增强 few-shot detector，且强 SSOD detector 往往带来更强 FSOD detector。PS-TTL 则在测试时使用 mean-teacher 自训练发现 novel instances，并用 prototype-based soft labels 处理低置信伪标签的分类混淆。这些工作共同说明，few-shot 检测不应只依赖 support set 微调，而应把 unlabeled target images 当作潜在 novel 类分布补充。

零样本和开放词汇检测的伪标签来源更偏语义模型。PB-OVD 使用预训练视觉语言模型从大规模 image-caption pairs 自动生成 pseudo bounding-box labels，以扩大训练类别集合；CORA 用 CLIP region prompting 和 anchor pre-matching 改善 region-level 识别与 unseen localization；DST-Det 用 CLIP 对背景 proposals 做 zero-shot 分类，把一部分原本会被当作背景的候选转为 novel class 训练样本；SAS-Det 针对开放词汇自训练中的 noisy PL 和 PL distribution changes，设计 split-and-fusion head 与周期性教师更新来稳定训练。

这类方法给本项目的启示是：零样本检测不是直接把开放词汇教师部署上线，而是把它变成一个训练期的候选生成器和语义校验器。Grounding DINO 可以利用类别名、短语和属性 prompt 给出高召回候选；YOLO-World 可以用更高速度生成开放词汇候选；DINOv3 可以从 dense feature 侧检查候选是否像“稳定物体”。最后仍应把这些信号蒸馏进 YOLO 学生，使部署期保持 YOLO-only。

4. 遥感与航拍小目标场景

遥感/航拍目标检测有几个与自然图像不同的约束：目标小且密集，任意方向和长宽比常见，背景纹理复杂，类别长尾明显，标注成本高，且同一类别在不同传感器、高度、城市形态下分布漂移。RS-PCL 用 teacher-student 伪标签和 consistency learning 处理 remote sensing images，并提出 Noisy Pseudo box Assignment 与 Scale-Invariant Learning；RemoteDPL 用 dense pseudo-labeling、多尺度融合、实例密度分支和两阶段筛选处理密集场景；Dual-Criterion Pseudo Label Selection 用分类置信和定位质量双准则，并在 DOTA-v1.5 的 10%、20%、30% 标注比例下报告 49.23、55.71、59.10 mAP。

开放词汇航拍检测也开始直接使用 VLM/VFM 教师。CastDet 使用 RemoteCLIP 作为额外全知教师，在学生-教师框架中提升 novel proposals 和分类，并在 VisDroneZSD novel categories 上达到 46.5% mAP，较当时 SOTA 高 21.0 mAP。OS-W2S 构建语言引导开放集航拍标注引擎，将词、短语、句子级语言指导引入航拍检测，训练后 Grounding DINO 在 sentence-level zero-shot transfer 上提升 31.1 AP50 和 34.7 Recall@10。RT-OVAD 则强调实时开放词汇航拍检测，在 DIOR、DOTA-v2.0、LAE-80C 上报告 87.7 AP50、53.8 mAP、23.7 mAP，并达到 34 FPS。

对当前仓库而言，遥感文献支持三项工程判断。第一，伪标签生成前应先做 tile/patch 切片，避免缩放到教师输入尺寸后小目标消失；第二，筛选指标应按小目标面积段单独监控，不能只看总体 precision；第三，DINOv3 或 RemoteCLIP 这类 VFM 更适合训练期补先验，而不是替代 YOLO 学生部署。仓库已有 Grounding DINO、YOLO-World、DINOv3 相关配置和评估脚本，这与文献方向一致。

5. DINOv1/v2/v3 在目标检测中的应用

5.1 DINOv1：从自监督注意力到无监督目标发现

DINOv1 即 Caron 等的 Emerging Properties in Self-Supervised Vision Transformers。它不是检测器，而是一种无标签自蒸馏 ViT 表征学习方法。原文指出，自监督 ViT 特征包含清晰的语义分割信息，这种性质在监督 ViT 和 CNN 中并不同样明显；小 ViT 的 k-NN ImageNet top-1 可达 78.3%，ViT-Base linear eval 达 80.1%。这说明 DINOv1 的价值在于 patch token 和 attention map 中自然出现 foreground/objectness，而不是直接输出类别框。

随后 TokenCut 等工作利用 DINO 自监督 ViT 特征构建 token graph，用 normalized cut 发现前景目标。TokenCut 在 VOC07、VOC12、COCO20K 无监督目标发现上分别较 LOST 提升 6.9%、8.1%、8.1%，并可扩展到 saliency detection 和 weakly supervised object detection。这条线对检测的贡献是“找到候选前景区域”，尤其适合无标注或极少标注时作为伪框/伪 mask 生成的前处理。局限是 DINOv1 的类别语义弱，patch 分辨率和目标边界也不足以直接替代检测器。

5.2 DINOv2：通用 frozen features、feature enhancer 与 pseudo labeller

DINOv2 把 DINO+iBOT 风格的自监督训练扩大到 142M curated images，并训练 ViT-g/14 等大模型，再蒸馏到 S/B/L 等可用尺寸。原文强调其特征在 image-level 和 pixel-level benchmarks 上都很强，且可不微调使用。对检测来说，DINOv2 的直接用法通常有三类：作为 frozen backbone 或辅助 backbone；作为 DETR/Mask R-CNN/ViTDet 的 feature enhancer；作为离线 labeller 或 feature alignment teacher。

Frozen-DETR 是一个代表：它不把 foundation model 直接替换为检测骨干，而是把冻结 CLIP/DINOv2 的 class tokens 和 patch tokens 作为 feature enhancer 注入 DETR。ai4scholar snippet 显示，该方法在多个 DETR 系基线上带来 2.7 到 4.0 AP 的提升，并指出收益更多来自高层语义理解而非纹理细节，能降低 false negative、classification error 和 background error。DINO Teacher 则在 domain adaptive object detection 中用冻结 DINOv2 ViT-G 训练 Faster R-CNN labeller，仅用源域数据生成目标域伪标签，并用 DINO feature alignment 推动学生学习更泛化的表示。

DINOv2 的限制也很清楚。它不是语言模型，不能独立解决开放词汇类别映射；它的 patch size 和冻结特征对极小目标可能不够细；如果直接作为部署 backbone，计算成本高于 YOLO 系列。因而在本项目中，DINOv2/DINOv3 更适合提供训练期 dense feature/objectness、对伪标签排序、做特征蒸馏或做对照实验，而不是替代 YOLO 学生。

5.3 DINOv3：面向 dense prediction 的高分辨率基础表征

DINOv3 的核心动机是：DINOv2 继续放大模型和训练周期时，dense feature maps 会退化；DINOv3 用 Gram anchoring 约束 patch feature 的关系结构，解决长程训练下 dense features 变差的问题。原文还引入 7B 参数 ViT 模型、constant schedules、high-resolution post-training、多学生蒸馏以及对 resolution/model size/text alignment 的 post-hoc 策略。ai4scholar 全文读取显示，DINOv3 在冻结视觉 backbone 的情况下报告 COCO detection mAP 66.1、ADE20k mIoU 63.0，并明确将目标检测列为 dense downstream task。

DINOv3 在检测中的用法可分成强、中、轻三档。强用法是像 DINOv3 原文那样冻结 7B/16 backbone，接 Plain-DETR 风格编码器/解码器，在 Objects365 和 COCO 上训练高性能 detector；这能验证上限，但计算成本高，不适合本项目默认部署。中等用法是 DINO-YOLO、DisDop 等思路，把 DINOv3 特征或蒸馏先验注入 YOLO/轻量检测器：DINO-YOLO 在土木工程小数据场景报告裂缝、PPE、KITTI 等任务分别提升 12.4%、13.7%、88.6%，但有 2-4 倍推理开销。轻量用法是仅在训练期读取 DINOv3 patch/dense features，作为 objectness teacher、coverage subset selector、feature distillation target 或 pseudo label rescoring signal，最终学生仍为 YOLO。

对航拍小目标，DINOv3 最有价值的不是直接给类别，而是提供“高分辨率 dense semantic consistency”。航拍图像中的小车、行人、摩托车常在开放词汇教师中低分，但 DINOv3 patch 相似图可能仍能显示局部前景结构。将 Grounding DINO/YOLO-World 的类别候选与 DINOv3 的 dense foreground/objectness 结合，比单独依赖任一教师更稳。报告建议优先探索 DINOv3 作为离线 teacher signal：对候选框内部/边界/邻域 patch 做相似性统计，形成 pseudo-label quality score。

名称 本质 检测中的典型使用 已报告效果或关键证据 本项目建议
DINOv1 无标签自蒸馏 ViT 表征学习。 attention/patch feature 前景发现、无监督目标发现、弱监督定位。 ImageNet linear eval 80.1%；TokenCut 在 VOC/COCO 无监督目标发现较 LOST 提升约 6.9-8.1 个百分点。 可作为历史基线，不建议作为当前主教师。

6. Grounding DINO 与 YOLO-World 作为训练期教师

Grounding DINO 将 DETR-style DINO 检测器与 grounded pre-training 结合，通过 feature enhancer、language-guided query selection 和 cross-modality decoder 融合视觉与语言。原文报告 COCO zero-shot transfer AP 52.5、ODinW zero-shot mean AP 26.1。它适合作为高召回、强语义的离线自动标注器，尤其当目标类别可以用类别名、同义词、短语或属性描述时。缺点是推理慢、prompt 敏感、框对小目标可能偏粗，且直接部署成本高。

YOLO-World 则把 YOLO 的实时性与开放词汇语义结合，提出 RepVL-PAN 和 region-text contrastive loss，在 LVIS 上 zero-shot AP 35.4，并报告 V100 上 52.0 FPS。它比 Grounding DINO 更接近部署速度，但作为开放词汇检测器仍可能受域差异和文本 prompt 影响。对本项目而言，YOLO-World 是很好的训练期候选教师和部署可行性对照，但默认学生仍可选择普通 YOLO-only，以避免开放词汇文本分支增加部署复杂度。

多传感器和航拍文献中，Grounding DINO 自动标注 + YOLO 学生训练已经被直接验证。Son 与 Jung 使用 Grounding DINO 自动标注多设备图像，再训练 YOLOv8 学生，报告自动生成标签不会造成性能退化，自动标注加手工标注能进一步提升。零标签航拍海事监控工作也强调重型 VLM 作为 autonomous annotator，训练轻量学生用于边缘 UAV；其中 tiling 被用来保持高空小目标分辨率。这些做法与本项目规则一致：DINOv3、Grounding DINO、YOLO-World 默认保留为训练期教师或伪标签源，部署期学生保持 YOLO-only。

7. 效果对照与适用边界

表 3：代表方法的效果证据
方法 任务设定 关键机制 报告效果 边界
Unbiased Teacher SSOD，COCO/VOC 少标注。 EMA teacher + class-balance loss。 COCO 1% 标注较 SOTA +6.8 mAP；0.5/1/2% 标注较监督 baseline 约 +10 mAP。 仍依赖分类置信筛选，开放词汇能力有限。
Soft Teacher 端到端 SSOD。 教师分数加权分类损失 + box jittering 选可靠框。 全 COCO baseline 40.9 mAP 经未标注 COCO 提升到 44.5；Swin detector 58.9 到 60.4。 定位过滤有效，但对小目标低召回仍需额外机制。
Dense Teacher SSOD。 dense pseudo-label 替代 sparse boxes，减少后处理信息损失。 摘要报告在 COCO/VOC 多种设置优于 pseudo-box 方法。 实现与检测头强相关，迁移到 YOLO 需设计 dense target 对齐。
OneTeacher / SSOD-YOLO 一阶段/YOLO 半监督检测。 multi-view pseudo-label refinement、decoupled semi-supervised optimization、augmentation-guided pseudo-label optimization。 OneTeacher 报告较 Unbiased Teacher 有 15.0% 相对 AP gain；SSOD-YOLO 报告较 OneTeacher/Unbiased Teacher +1.7/+3.9 mAP50-95。 YOLO 训练技巧会稀释 SSOD 收益，需控制 mosaic、强增强和多任务损失冲突。
Adaptive Pseudo Labeling FSOD 半监督 few-shot detection。 class-adaptive threshold filtering + 两路伪标签融合。 PASCAL VOC / MS COCO 验证有效，目标是缓解 novel class 数据稀缺和 base bias。 依赖初始 few-shot detector 质量；类别分位数在样本极少时可能不稳。
CTPL for RS FSOD DIOR 5-shot/class 遥感检测。 confidence-tiered pseudo labels，中置信标签补覆盖。 42.3% mAP@50，较 GT-only 32.3% 有 +31.0% 相对提升；高置信-only 几乎不提升。 教师弱时 curriculum progressive training 可能累积错误。
CastDet 开放词汇航拍检测。 RemoteCLIP 额外教师 + dynamic label queue。 VisDroneZSD novel categories 46.5% mAP，较 SOTA +21.0 mAP。 依赖 RemoteCLIP 和开放词汇训练设计，需处理 base/novel 平衡。
Grounding DINO 开放集/指代表达检测。 语言引导 query selection + cross-modality decoder。 COCO zero-shot AP 52.5，ODinW zero-shot mean AP 26.1。 慢、prompt 敏感；小目标需 tiling 与后处理。
YOLO-World 实时开放词汇检测。 RepVL-PAN + region-text contrastive loss。 LVIS 35.4 AP，V100 52.0 FPS。 域外航拍仍需 fine-tune 或蒸馏；文本分支增加部署复杂度。
DINOv3 自监督 VFM 用于 dense prediction/detection。 Gram anchoring + high-resolution dense features + frozen backbone detector。 原文报告 COCO detection mAP 66.1、ADE20k mIoU 63.0。 强模型计算成本高，默认更适合训练期 teacher/distillation。

从效果证据看，收益最大的一类方法往往不是单独“换一个更强教师”，而是同时提升伪标签质量和伪标签覆盖率。Unbiased Teacher 解决类别偏置，Soft Teacher 解决定位可靠性，LabelMatch 解决分布/实例匹配，Dense Teacher 保留 dense information，开放词汇方法扩大类别空间，DINOv3 提供 dense feature prior。对少标注航拍小目标而言，这些策略必须组合使用，因为单一置信阈值策略很容易在小目标召回和噪声之间失衡。

也要注意负面边界。第一，开放词汇教师的“能检测任意词”不等于“能在航拍小目标上给高质量框”；prompt、切片尺度和 NMS 都会显著影响伪标签。第二，DINOv3 的高分辨率 dense feature 很强，但它没有天然类别文本接口，不应替代 Grounding DINO 或 YOLO-World 的语义角色。第三，SSOD 的 mAP 提升常来自 COCO/VOC，自然图像结论迁移到 VisDrone/DOTA/DIOR 时必须重新验证 AP_small、crowded scenes、per-class recall 和 pseudo label precision。

8. 对本项目的实验建议

推荐主线 A：多教师离线伪标签

使用 Grounding DINO 生成高召回文本语义候选，YOLO-World 生成快速开放词汇候选，DINOv3 生成 dense objectness/coverage score。三者通过统一 schema 融合：类别来自文本教师，框质量来自多尺度一致性和 jitter，前景性来自 DINOv3 patch features。输出只作为训练数据，不参与部署。

推荐主线 B：小目标分层阈值

按类别、面积段和 tile 尺度维护阈值。高置信框进入硬标签训练；中置信框进入 soft-label/weighted loss；低置信但 DINOv3 foreground 强的框进入 objectness 或 feature distillation。每组阈值写入 configs/，避免脚本硬编码。

推荐主线 C：YOLO 学生蒸馏

保持 deployment-time student YOLO-only。训练时可添加 DINOv3 feature/objectness auxiliary loss、teacher box consistency loss、relation distillation 或 pseudo-label replay；推理导出时移除教师与辅助头。

推荐主线 D：面向 AP_small 的评估

除了 mAP，还应报告 AP_small、per-class pseudo label precision/recall、每张图伪标签密度、低/中/高置信标签占比、teacher disagreement、NMS 前后候选损失率。小目标伪标签策略如果只提升总体 AP 但降低 AP_small，不应作为主线。

8.2 伪标签质量评分建议

建议为每个候选框计算一个结构化质量向量，而不是一个单分数：class_score 来自 Grounding DINO/YOLO-World；box_stability 来自多尺度、flip、jitter 后 IoU；objectness_score 来自 DINOv3 patch foreground；teacher_agreement 来自多教师框匹配；area_bucket 标记 small/medium/large；class_bucket_threshold 来自类别分位数。训练时再由配置决定如何把质量向量映射为硬标签、软标签或 objectness-only 标签。

这种设计能把文献策略统一起来：Unbiased Teacher 的类别平衡对应 class_bucket_threshold；Soft Teacher 的加权损失对应 class_score 权重；box jittering 对应 box_stability；DINOv3/DINO Teacher 对应 objectness_score 和 feature alignment；开放词汇教师对应 class_score 与 prompt ensemble。工程上也便于做消融，不会让每个实验都变成独立脚本。

8.3 风险与检查项

第一，伪标签文件、数据集和 checkpoint 不应提交；只提交配置、脚本和报告。第二，Grounding DINO/YOLO-World 的 prompt 需要版本化，类别同义词和负 prompt 都会影响标签分布。第三，tile-based 伪标注要记录原图坐标映射，避免小目标框在 tile 合并时出现重复或偏移。第四，DINOv3 特征若用于离线缓存，应明确缓存目录在 runs/data 外且被 gitignore 覆盖。第五，所有实验都要保留 student-only inference 的导出检查，避免教师依赖意外进入部署路径。
